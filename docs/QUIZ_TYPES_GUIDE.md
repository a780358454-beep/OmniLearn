# 📝 دليل ومواصفات أنواع الاختبارات التفاعلية السبعة (7 Quiz Types)

تم تجهيز محرك التقييم لدعم 7 أشكال تفاعلية تمكّن المؤلف من صياغة اختبارات ذكية تناسب أي تخصص:

---

### 1. اختيار من متعدد أحادي (Single Choice)
* **الوصف:** سؤال مباشر يتطلب اختيار إجابة صحيحة واحدة فقط من بين 4 بدائل.
* **الاستخدام البرمجي:** مفاهيم، تعاريف، مخرجات دوال.
* **الاستخدام الطبي:** تشخيص أساسي، تحديد جرعة دواء.

### 2. اختيار متعدد البدائل (Multiple Choice - Checkboxes)
* **الوصف:** سؤال يتطلب تحديد جميع الإجابات الصحيحة (2 أو أكثر) ويُقيّم بناءً على اكتمال الاختيارات.
* **الاستخدام البرمجي:** تحديد ميزات إطار عمل، اختيار بروتوكولات الشبكة.
* **الاستخدام الطبي:** تحديد أعراض مرض معين.

### 3. ترتيب أسطر الكود والخطوات (Sequence & Code Ordering)
* **الوصف:** سحب وإفلات العناصر المبعثرة لإعادة ترتيبها بالترتيب المنطقي الصحيح.
* **الاستخدام البرمجي:** ترتيب أسطر كود لإنشاء دالة أو دورة حياة السبرنت.
* **الاستخدام الطبي:** ترتيب خطوات الإنعاش القلبي (CPR) أو الإسعاف الأولي.

### 4. ملء الفراغات الموجهة (Fill-in-the-Blank / Cloze)
* **الوصف:** إكمال كلمة مفقودة داخل جملة أو سطر برمجي عبر حقل إدخال ذكي يقبل مرادفات الإجابة.
* **الاستخدام البرمجي:** كتابة اسم الكلمة المفتاحية المفقودة (مثل `async`, `final`, `Sprint`).
* **الاستخدام الطبي:** كتابة اسم الإنزيم أو العضو الحيوي المفقود.

### 5. مطابقة الأزواج والمفاهيم (Pair Matching)
* **الوصف:** النقر على المصطلح ثم النقر على تعريفه أو رمزه لربطهما معاً.
* **الاستخدام البرمجي:** ربط الأنماط المعمارية بتعريفاتها (مثل MVC, Singleton).
* **الاستخدام الطبي:** ربط كل عرض مرضي بالفحص المخبري المناسب.

### 6. صح أو خطأ مع التبرير المعرفي (True / False with Insights)
* **الوصف:** زر سريع (صحيح / خطأ) يتبعه كشف فوري للتعليل المنطقي والمفهوم الصحيح.
* **الاستخدام العام:** تصحيح المفاهيم الشائعة الخاطئة وتثبيت القواعد الأساسية.

### 7. تحدي دراسة الحالة والسيناريو العملي (Case Study Challenge)
* **الوصف:** بطاقة سيناريو معقدة تعرض موقفاً واقعياً ومجموعة من الحلول المقترحة مع تحليل هندسي أو سريري معمق لاختيار أفضل قرار.
* **الاستخدام البرمجي:** قرارات معمارية البرمجيات، المفاضلة بين الأمان وسرعة الإطلاق.
* **الاستخدام الطبي:** دراسة حالة مريض في غرفة الطوارئ واتخاذ قرار التدخل السريري.
