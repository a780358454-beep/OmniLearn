# 🏛️ المعمارية البرمجية لمحرك التعلم الشامل: OmniLearn Core

تم بناء هذا النظام على معمارية معيارية ومجردة بالكامل (**Domain-Agnostic Engine**) بحيث تنفصل النواة البرمجية تماماً عن المحتوى التخصصي.

---

## 🎯 1. المبدأ المعماري: كيف تعيد استخدام النواة لبناء أي تطبيق آخر؟

النواة لا تحتوي على أي كود يفرض تخصصاً معيناً. كل تخصص أو مجال يُعامل داخل النظام كـ **Curriculum Domain**:

```
                  ┌───────────────────────────────┐
                  │    OmniLearn Core Engine      │
                  │  (التقييم، التلعيب، الأدوار) │
                  └───────────────┬───────────────┘
                                  │
         ┌────────────────────────┼────────────────────────┐
         ▼                        ▼                        ▼
┌──────────────────┐    ┌──────────────────┐    ┌──────────────────┐
│  تطبيق برمجي      │    │  تطبيق طبي سريري  │    │  تطبيق لغات      │
│  (CodeSphere)    │    │  (MedSphere)     │    │  (LinguaSphere)  │
│  • هندسة برمجيات │    │  • إسعافات وطوارئ│    │  • قواعد ومفردات │
│  • تطبيقات موبايل │    │  • تشخيص سريري   │    │  • استماع ومحادثة│
└──────────────────┘    └──────────────────┘    └──────────────────┘
```

### خطوات استنساخ النواة لتطبيق جديد (مثلاً تطبيق طبي):
1. **تغيير الهوية من لوحة تحكم الأدمن أو في `AppBrandingConfig`:**
   * تغيير اسم التطبيق إلى `MedSphere`.
   * اختيار أيقونة `local_hospital`.
   * اختيار باليتة الألوان المناسبة (مثلاً الأخضر الطبي أو الأزرق السماوي).
2. **إنشاء المسار المخصص (Curriculum):**
   * إضافة مسار `Medical Sciences Track`.
   * إضافة المقررات (مثل: علم الأدوية، الإسعافات الأولية).
3. **تصدير واستيراد المنهج:**
   * يمكنك تصدير المنهج كملف `JSON` واستيراده في أي نسخة جديدة بضغطة زر واحدة.

## 👥 2. مصفوفة الأدوار والصلاحيات (Role-Based Access Control - RBAC)

يدعم النظام 3 أدوار متكاملة:

| الميزة | مدير النظام (Admin) | مؤلف المحتوى (Creator) | الطالب / المتعلم (Student) |
| :--- | :---: | :---: | :---: |
| **تغيير هوية التطبيق والأيقونة والألوان** | ✅ | ❌ | ❌ |
| **إنشاء وإدارة حسابات المؤلفين** | ✅ | ❌ | ❌ |
| **حوكمة المحتوى (نشر / تعليق / مراجعة)** | ✅ | ❌ | ❌ |
| **إنشاء مسارات وتخصصات جديدة** | ✅ | ❌ | ❌ |
| **إضافة مقررات ووحدات ودروس** | ✅ | ✅ | ❌ |
| **بناء أسئلة الاختبارات التفاعلية (7 أنواع)** | ✅ | ✅ | ❌ |
| **تصدير واستيراد المناهج (JSON)** | ✅ | ✅ | ❌ |
| **دراسة الدروس وحل الاختبارات وحصد الـ XP** | ✅ | ✅ | ✅ |

## 🔄 3. دورة حياة نشر المحتوى (Publishing Governance)

كل درس أو مقرر يمر بدورة حوكمة دقيقة يراقبها الأدمن:
1. `Draft` (مسودة): الدرس قيد الكتابة بواسطة المؤلف وغير متاح للطلاب.
2. `In Review` (قيد المراجعة): أرسله المؤلف لمراجعة جودة المحتوى والأسئلة.
3. `Published` (منشور): معتمد ومتاح لكافة الطلاب على واجهة التعلم.
4. `Suspended` (معلق): تم إيقافه بقرار من الإدارة دون حذفه.

## 🌍 4. معمارية التدويل وتعدد اللغات (i18n Architecture)
* تم بناء `I18nService` ليدير الاتجاهات ديناميكياً:
  * **العربية:** اتجاه من اليمين لليسار (RTL).
  * **الإنجليزية:** اتجاه من اليسار لليمين (LTR).
* كافة النصوص معرفة عبر مفاتيح برمجية تسمح بإضافة أي لغة ثالثة بسهولة فائقة داخل `app_translations.dart`.

## 📱 5. معمارية واجهة المتعلم الرئيسية (Learner Home Architecture)

تمت إعادة هندسة الواجهة الرئيسية للمتعلم (`LearnerHomeScreen`) وفق أحدث معايير تجربة المستخدم التعليمية:
1. **بطاقة المادة الحالية الفعالة (Active Subject Hero Card):**
   * تعرض المادة قيد الدراسة حالياً مع كودها، وصفها، وشريط إنجاز دقيق يوضح عدد الدروس المنجزة ونسبة التقدم.
   * زر إجراء مباشر ينقل المتعلم إلى أول درس غير مكتمل (`متابعة التعلّم: [اسم الدرس]`).
2. **شريط التمرير الجانبي لباقي المقررات (Horizontal Courses Carousel):**
   * شريط تمرير أفقي سلس (`scrollDirection: Axis.horizontal`) يعرض بطاقات المواد الأخرى مع شريط تقدم مصغر.
   * النقر على أي مادة يحددها فوراً كمادة نشطة بالصفحة دون الحاجة لإعادة تحميل.
3. **نافذة استعراض كافة المواد والمناهج (All Courses Bottom Sheet):**
   * زر مخصص يفتح نافذة سفلية كاملة لاستعراض وتصفية كافة المقررات عبر التخصصات المختلفة، مع إمكانية تصدير بيانات الأبحاث CSV.

## 🔐 6. دورة حياة التنقل والمصادقة الفورية (Immediate Auth & Navigation Lifecycle)
* **الانتقال الفوري دون الحاجة لإعادة التشغيل:**
  * عند نجاح تسجيل الدخول (`AppStateService.login`) أو إنشاء الحساب (`register`)، يتم استدعاء `Navigator.of(context).pushAndRemoveUntil` مباشرة إلى `LearnerHomeScreen`.
  * عند تسجيل الخروج (`logout`)، يتم تفريغ الجلسة والانتقال الفوري إلى `LoginScreen`.
  * بوابة التطبيق (`RootGate`) مغلفة بـ `AnimatedBuilder` لمراقبة جاهزية النظام، مما يضمن مرونة وتفاعلية كاملة على مستوى الشجرة.
* **الأمان:**
  * تشفير كلمات السر بـ SHA-256 مع 10,000 تكرار وملح تشفيري عشوائي (Salt) مع فحص ذي زمن ثابت (Constant-time comparison) لمنع هجمات التوقيت (Timing attacks).
