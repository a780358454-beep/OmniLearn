# معايير الجودة — OmniLearn

> قواعد قابلة للفحص، لا نوايا. أي مخالفة تُعدّ عيبًا يجب تسجيله.

## 1. التصميم

| المعيار | القيمة | كيف يُفحص |
|---|---|---|
| شبكة المسافات | 4 · 8 · 12 · 16 · 20 · 24 · 32 · 48 | لا قيمة خارج القائمة |
| الانحناء | 8 حقول · 12 بطاقة · 16 صفيحة · 28 حوار | مراجعة بصرية |
| هدف اللمس | ≥ 48×48 | قياس فعلي |
| تباين النص | ≥ 4.5:1 (عادي) · ≥ 3:1 (كبير) | أداة تباين |
| أحجام النص | عنوان 26 · عنوان فرعي 20 · نص 16 · صغير 14 · تسمية 12 | لا نص أصغر من 12 |
| ارتفاع السطر | ≥ 1.5 (عربي 1.6) | فحص |
| الأيقونات | مجموعة واحدة (Material Symbols) بمقاس 20/24 | لا خلط مجموعات |
| الحالات | لكل شاشة: تحميل · فارغ · خطأ · نجاح | جرد الشاشات |
| الحركة | 100–300ms، منحنى واحد | لا حركة > 600ms |

## 2. العربية وRTL

| القاعدة | السبب |
|---|---|
| `EdgeInsetsDirectional` / `AlignmentDirectional` فقط | `left/right` تنكسر في RTL |
| `Directionality` فوق الـNavigator (`MaterialApp.builder`) | الشاشات المدفوعة لا ترث اتجاه `home` |
| عزل الكود بـ`Directionality.ltr` | النص اللاتيني داخل العربية يُقلب |
| لا `letter-spacing` سالب مع العربية | يفكك الاتصال |
| أرقام لاتينية موحّدة + فاصلة `،` | اتساق |
| وزن 400/500/600/700 فقط | الأوزان المتطرفة تسيء للعربية |
| خط مضمَّن (IBM Plex Sans Arabic / Tajawal) | لا اعتماد على خط الجهاز |

## 3. البيانات والعرض

| القاعدة | التطبيق |
|---|---|
| لا نص عربي مثبت داخل الشاشات | كل نص عبر مفاتيح ترجمة |
| لا لون مثبت (`Color(0xFF…)`) في `features/` | كل لون من `ColorScheme`/`ColorTokens` |
| لا منطق في الواجهة | الواجهة تعرض؛ الخدمة تقرر |
| كل حالة تحميل لها حالة خطأ | لا دائرة أبدية |
| كل بيانات محفوظة لها `schemaVersion` | ترحيل آمن |
| معرّفات المحتوى ثابتة لا تُعاد | تقدّم المستخدم لا يضيع |

## 4. الأداء

| الميزانية | الحد |
|---|---|
| زمن الإقلاع البارد | < 2.5 ثانية على جهاز متوسط |
| حجم APK (arm64) | < 15 MB |
| إطارات | 60fps ثابت في التمرير |
| استجابة اللمس | < 100ms |
| ذاكرة | < 150 MB |
| العمليات الثقيلة | لا تُنفَّذ على الخيط الرئيسي |

## 5. الوصولية

- تباين AA على الأقل في الوضعين.
- لا معلومة باللون وحده (صح/خطأ له أيقونة ونص).
- دعم تكبير الخط حتى 1.3× دون قطع.
- تسميات `tooltip`/`semanticLabel` للأزرار الأيقونية.
- أهداف لمس متباعدة ≥ 8.

## 6. الأمان (حدود معلنة)

| البند | الحالة | الحد |
|---|---|---|
| كلمة السر | مجزَّأة + ملح + 10k تكرار | ليست bcrypt؛ لا خادم |
| الجلسة | معرّف مستخدم محفوظ | يمكن تجاوزه بالعبث بملفات التطبيق |
| المحتوى المستورد | تحقق مخطط | لا توقيع رقمي |
| الشبكة | لا اتصال حاليًا | HTTPS + بصمة عند تفعيل التحديث |

> **يجب ذكر هذه الحدود في تقرير المشروع** — الاعتراف بها أقوى من ادعاء أمان وهمي.
