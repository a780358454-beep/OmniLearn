# خطة المشروع v3 — OmniLearn

> هذا الملف هو مصدر الحقيقة الوحيد لحالة المشروع. أي ادعاء في أي وثيقة أخرى يجب أن يطابقه.
> آخر تحديث: 2026-10-25

## 1. الهدف
**محرك تعلّم عربي عام (Android)** — ليس مقيّدًا بمسار جامعي ولا بتخصص واحد.
أي مؤلف (مدير أو مشرف) يضيف مواد ودروسًا في أي مجال، والمستخدم يتصفّح ويختار ويتعلّم.
المحتوى قابل للتحديث دون إعادة بناء التطبيق، والتقدّم محفوظ، ولكل مادة مكتملة شهادة،
مع نموذج مجاني/مدفوع بإعلان بعد الدرس.

**المواد الجامعية السبع هي أول محتوى، لا هوية المشروع.**

## 5. التحديث المباشر للمحتوى (OTA)
### لماذا يفرض نقل المحتوى إلى JSON
المحتوى الحالي مضمَّن في Dart، وأي تعديل يتطلب إعادة بناء APK. التحديث المباشر **يستلزم** أن يكون المحتوى بيانات.

### التدفق
1. التطبيق يقرأ `assets/content/manifest.json` (بذرة) عند أول تشغيل.
2. عند وجود شبكة: يطلب `content/manifest.json` من عنوان ثابت (config).
3. يقارن `contentVersion`؛ إن الأحدث أعلى: ينزّل الحزمة.
4. يتحقق من `sha256` ومن `minAppSchema` ثم يحلّل المخطط.
5. يخزّن النسخة الجديدة في `pending/`، ويبدّل عند الإقلاع التالي (تبديل ذري).
6. عند فشل أي خطوة: يبقى على النسخة السابقة (rollback تلقائي).

### صيغة المانيفست
```json
{
  "schemaVersion": 3,
  "contentVersion": 12,
  "minAppVersion": "1.0.0",
  "files": [{"path": "curricula/cs.json", "sha256": "..."}]
}
```

### استقرار المعرّفات (شرط عدم فقدان التقدم)
- معرّف الدرس/المادة **ثابت لا يُعاد استخدامه**.
- حذف درس لا يحذف سجل تقدّمه (tombstone) بل يُستثنى من المقام.

### حدود أمنية معلنة
HTTPS + بصمة SHA-256 يمنعان التلف، ولا يمنعان خادمًا مخترقًا. التوقيع الرقمي (Ed25519) عمل مستقبلي موثّق.

## 6. ترحيل البيانات
- كل كائن مخزَّن يحمل `schemaVersion`.
- `MigrationRunner` يطبّق تحويلات مرتّبة 1→2→3.
- قبل أي ترحيل: نسخة احتياطية بالمفتاح `*_backup`.
- البيانات القديمة غير القابلة للترحيل تُحفظ ولا تُمحى؛ يُبدأ تخزين جديد مع تسجيل الحدث.
- اختبار إلزامي: بيانات v1 → ترحيل → لا فقدان في `xp` و`completedLessonIds`.

## 7. الإعلانات (النسخة المجانية)
| القاعدة | القيمة |
|---|---|
| الموضع | شاشة كاملة بعد إكمال الدرس فقط |
| التكرار | إعلان واحد لكل درس، وتبريد 90 ثانية |
| الاستثناءات | لا إعلان في الاختبار، ولا في لوحة الأدمن/الاستوديو، ولا قبل أول درس |
| السلوك | زر تخطٍّ بعد 5 ثوانٍ |
| المدفوع | `isPremium = true` → لا إعلان |

**التنفيذ:** طبقة مجرّدة `AdService` + `HouseAdSlot` (إعلان داخلي) الآن، ومكان جاهز لـAdMob لاحقًا.
**سبب التأجيل:** AdMob يحتاج حسابًا وApp ID وموافقة UMP وسياسة خصوصية؛ لا شيء منها متاح الآن.
**الأخلاقيات:** لا إعلانات مخصصة للقُصّر افتراضيًا، وشاشة موافقة قبل أي جمع بيانات.
